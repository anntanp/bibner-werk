# BibNER-Werk — Scripts

All scripts are standalone Python files in `scripts/py/`, or shell scripts in `scripts/sh/`. Each has a header block: purpose, usage, inputs/outputs, dependencies, assumptions.

## Shell scripts

| Script | Status | Description |
|---|---|---|
| `sh/resume_folds.sh` | Done, 2026-07-10, updated 2026-07-11 | Waits for the current user's `train_gliner_silver.py` processes to finish, then relaunches every fold missing a "Saved checkpoint" line or showing any "Skipping batch due to CUDA OOM" warning (treated as compromised, not salvageable), capped at `-c` concurrent (default 3). Clears each relaunched fold's `models/gliner_fold{i}/` first — stale `checkpoint-N/` subdirs (`save_strategy="epoch"`) can survive a killed/crashed run and would otherwise collide with the new run's own checkpoint numbering. Written after a real incident: launching all k=10 fold replicates at once on a shared A100 (another tenant holding a fixed ~19 GiB) caused cascading OOM kills across 9/10 folds; a second incident showed 3 folds can die at the final-save step (after training+eval completed) if `load_best_model_at_end`'s internal reload OOMs — a path gliner's per-batch OOM catch doesn't cover. See `notes/fiz/bibner-werk/A5-finetuning-gliner-actual.md` #16–17, `A5-finetuning-workflow.md §7` |
